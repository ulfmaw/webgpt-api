讀取狀態…

首次只需在新視窗正常登入 ChatGPT。程式會自動偵測並接手，不需要關視窗、搬 Cookie 或按完成。每次生成測試會送出一則「Reply only: OK」。驗證失敗不會自動重開登入視窗。

標準 OpenAI API 設定

  1. 上面要先顯示生成測試通過。還沒登入就按「登入／更新登入」，在跳出的視窗登入 ChatGPT，登好不要自己關。
  2. 在工具裡選 OpenAI、Custom Provider 或 OpenAI-compatible。
  3. Base URL 填下方網址，API Key 貼本機 Key，Model 填 auto。這不是 ChatGPT 密碼，也不要貼到網路上。

這是標準 OpenAI 相容 API；一般聊天用 Chat Completions，Codex 這類工具用 Responses，網址相同。

API 位址

http://127.0.0.1:17841/v1

不用填設定的方式

  1. 在這個專案資料夾雙擊 webgpt.cmd，會開一個已自動帶好本機 API 設定的終端。
  2. 要直接開工具，使用 webgpt.cmd 工具名，例如 webgpt.cmd codex 或 webgpt.cmd opencode。
  3. Codex 會自動使用專用 profile；其他支援 OpenAI 相容環境變數的命令列工具會自動收到網址、Key 和 auto 模型。
桌面版工具若不讀取環境變數，才使用上方的複製按鈕；服務不會修改第三方程式的帳號或設定檔。
