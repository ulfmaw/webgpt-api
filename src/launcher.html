讀取狀態…

首次只需在新視窗正常登入 ChatGPT。程式會自動偵測並接手，不需要關視窗、搬 Cookie 或按完成。每次生成測試會送出一則「Reply only: OK」。驗證失敗不會自動重開登入視窗。

接到別的程式，照這四步

  1. 上面要先顯示生成測試通過。還沒登入就按「登入／更新登入」，在跳出的視窗登入 ChatGPT，登好不要自己關。
  2. 按「複製網址」，貼到程式裡的 API 位址、Base URL 或接口地址。結尾要有 /v1。
  3. 按「複製本機 API Key」，貼到 API Key。這不是 ChatGPT 密碼，也不要貼到網路上。
  4. 模型填 auto，就跟著控制頁的選擇。程式若要選協定，選 OpenAI 相容。一般聊天用 Chat Completions，Codex 這類用 Responses，位址都是同一個。金鑰只給這台電腦用。
