預設為 ChatGPT 一般對話的原生 Auto。推理強度已經在模型選項裡，不用另外填。「帳號已提供・尚未實測」只表示清單已讀到，不代表要重登。測試成功才會保存，失敗就留著原來的設定。

接到別的程式

  1. 按「複製 API 網址」，貼到程式的 API 位址。結尾要有 /v1。
  2. 按「複製 API Key」，貼到 API Key。這不是 ChatGPT 密碼。
  3. 模型填 auto 或不填，就跟著這一頁的選擇。程式若要選協定，選 OpenAI 相容。
