# 模型適配驗證門檻

## 目前結論

最高檔自動選擇、額度降檔、會員變更及恢復升檔尚未當成已完成功能。
一般文字能生成，不代表這些功能已完成。離線測試也不是網站行為的證據。
網站傳輸目前沒有自動降檔規則。

## 每條規則啟用前

1. 在真實網站觀測對應狀態與機器可讀訊號，確認作用範圍是該檔、該模型或整個帳號。只有錯誤名稱、HTTP 狀態、Retry-After 或「已鎖定」文字不夠。
2. 對照選單、實際送出的模型及推理強度、回覆的模型資訊。模型名稱一致也不能單獨證明推理強度生效。
3. 建立不含帳號、對話、憑證或原始日誌的最小結構測試。區分觀測到的欄位形狀與自行合成的測試值，不把 mock 說成實測。
4. 測試相似但不應降級的反例，以及開始輸出前／後、斷線、取消、併發與重啟。確認不重複輸出、不破壞上下文、不將半份回答保存成完成。
5. 實機驗證降檔後的確切模型與強度，並驗證恢復條件。記錄無敏感資料的驗收結果後才接入生產傳輸。

## 驗收表

| 項目 | 現有證據 | 尚缺的實機驗證 | 狀態 |
| --- | --- | --- | --- |
| 取得檔位結構 | models 回傳 versions/intelligence_presets，含模型、強度與順序 | 不同方案、最新權限與剩餘額度是否反映在同一資料 | 部分觀測 |
| 選指定檔位 | 選單能讀到版本與檔位，請求會帶上對應的 model 與 effort | 回覆的實際模型與所選檔位一致。單一帳號的一次結果不能寫成所有人的行為 | 尚未當成完成功能 |
| 額度用完降檔 | 無對應真實額度耗盡案例 | 精確錯誤、額度作用範圍、下一檔完整生成 | 未驗證 |
| 會員變更重選 | 無會員變更實測 | 權限更新、快取失效、下一檔完整生成 | 未驗證 |
| 額度恢复升檔 | 無完整冷卻到恢復案例 | 真實重置訊號及恢復後使用最高檔 | 未驗證 |
| 中途失敗 | 已實測本機取消後回收與下一次生成 | 遠端真實額度錯誤在串流前／後的行為 | 部分觀測 |

不為製造案例刻意耗盡週額度，也不自動更動訂閱。沒有對應帳號或狀態就維持未驗證；可測可逆的本機案例，但不得替代缺少的網站證據。
